# Telangana Multi-Year Mandi Price Data — Source Research

**Purpose:** Identify authoritative, ideally free/public sources of genuine *multi-year* Telangana (and general India) agricultural mandi/market price data, to backfill history beyond the current `historical_mandi_prices.csv` (all-India, single calendar year 2025 only, 85,025 Telangana rows / 13 districts / 188 markets / 118 commodities within 2025).

**Method:** Web search + direct fetch of live pages/APIs on 2026-08-17. Every claim below is either (a) directly observed from a fetched page/API response, or (b) explicitly marked as unverified/could-not-confirm. No dataset statistics were invented.

## Detailed Findings by Source

### 1. CEDA Agri Market Data (Centre for Economic Data & Analysis, Ashoka University)

- **URL:** https://agmarknet.ceda.ashoka.edu.in/ (portal), https://ceda.ashoka.edu.in/data-portal/ (parent), https://api.ceda.ashoka.edu.in/documentation/ (API, Swagger UI — content not renderable via static fetch in this session)
- **Organization / authority:** CEDA, an academic research center at Ashoka University. Their underlying raw data is sourced from the same Ministry of Agriculture and Farmers Welfare / AGMARKNET pipeline as the government portals — CEDA's value-add is cleaning, aggregation, and a queryable interface, not a new primary data collection effort.
- **Years available:** The site's live query widget (as rendered by our fetch) showed a sample date range of 2025-04-22 to 2025-10-30, i.e., current data is present. Independently, the CEDA **API Terms & Conditions page** (https://ceda.ashoka.edu.in/api-terms-conditions/), which we fetched directly, requires users to cite the data as **"CEDA Agri Market Data (CEDA-AMD), 2000–2023"** — this citation string is CEDA's own official framing of their dataset's vintage. Third-party summaries found via search additionally described coverage "from 2000 to present" and "updated monthly," but we could not directly confirm live 2024–2026 data ourselves (the JS-rendered API docs page did not yield readable content). **Treat "2000–2023" as the only self-declared, directly-verified range; anything beyond that is not confirmed.**
- **Geographic coverage:** State and district-level filtering was directly observed in the fetched UI (dropdowns for "All India"/state, "All districts"). Market-level (mandi) granularity was not confirmed in what we could render.
- **Commodities:** Web search results (not independently confirmed via direct fetch of a full commodity list) describe "over 300 agricultural commodities from over 2,700 mandis across India."
- **Fields:** Confirmed via fetch: modal price, minimum price, maximum price, price changes, and arrival quantities, by date.
- **Mechanism:** Both a web query/visualization tool (timeseries, heatmap, bar chart, "Download Data" and "Download charts" buttons) **and** a documented REST API at `api.ceda.ashoka.edu.in` (Swagger-based). This is the only candidate source in this research where a genuine programmatic historical-range pull was confirmed to exist as a stated product ("Use our Data Portal API to access raw, frequently updated data").
- **Format:** Not explicitly stated in what we fetched (likely CSV/JSON given "Download Data" + API), not directly confirmed.
- **Licensing / terms — IMPORTANT CAVEAT:** Directly fetched from the CEDA API Terms & Conditions page:
  - **Free for non-commercial use only.** The terms state "users are free to download, display or include the data in other products for non-commercial purposes" — this phrasing implies commercial use is restricted or requires separate arrangement.
  - Attribution required: cite as "CEDA Agri Market Data (CEDA-AMD), 2000-2023"; CEDA logo required on any visualization; credit line "Centre for Economic Data & Analysis, Ashoka University."
  - No warranties on data accuracy; CEDA can revoke access for terms violations.
  - **This is a real blocker for YieldAI if YieldAI is (or becomes) a commercial product** — the license terms as found would need explicit clarification/permission from CEDA before production commercial use, not just research use.
- **Schema join potential:** State + district + commodity + min/max/modal price fields align well conceptually with the existing CSV schema (State/District/Market/Commodity/Variety/Grade/Arrival_Date/Min/Max/Modal). Market-level and Variety/Grade granularity were not confirmed present in CEDA's aggregated (monthly-level) product — CEDA appears to aggregate to state/district/monthly views for its dashboards, which may be **coarser** than the daily/market-level detail in the existing CSV. This needs direct verification via their API before assuming a clean join.

### 2. data.gov.in — "Variety-wise Daily Market Prices Data of Commodity" (AGMARKNET-sourced)

- **URL:** https://www.data.gov.in/resource/variety-wise-daily-market-prices-data-commodity (resource page — Swagger-UI-based SPA, static fetch only returned page shell/CSS, not the dataset description); related catalog: https://www.data.gov.in/catalog/current-daily-price-various-commodities-various-markets-mandi
- **Organization / authority:** Government of India, Open Government Data (OGD) Platform (data.gov.in), sourced from AGMARKNET (Directorate of Marketing & Inspection, Ministry of Agriculture and Farmers Welfare). This is the **same upstream source** as the existing `historical_mandi_prices.csv`.
- **Years available:** Not directly confirmed for this specific resource in this session (the resource metadata page is JS-rendered and returned only the app shell). However, we confirmed via search that data.gov.in separately publishes **year-specific fixed resources** for certain commodities (e.g., "Variety-wise Daily Market Prices of Tinda 2021" — found in search results, page fetch returned 403 so exact content not confirmed) — this suggests data.gov.in maintains **archival, year-labeled datasets in addition to the live/current one**, which is a meaningfully different structure than a single rolling CSV. Whether equivalent year-specific archives exist for 2022, 2023, and 2024 (and for the commodities/markets relevant to Telangana) was **not confirmed** — would require either browsing the full data.gov.in catalog under agriculture/AGMARKNET tags or querying the API directly with date filters.
- **API date-range capability:** We found third-party references (a market-linkage aggregator site, "finnid.in") mentioning that a similar data.gov.in mandi-price feed is synced with only a **"15-day rolling history."** This is a signal — **not a confirmation** — that the *live/current* resource used by many wrapper tools may only expose a short recent window via `filters[arrival_date]`, and that true multi-year backfill would depend on the separate year-archived resources (if they exist for the desired years/commodities) rather than the always-current one. **This distinction (rolling-current resource vs. year-archived resource) is the single most important thing to verify before committing engineering time here.**
- **Access mechanism:** REST API at `api.data.gov.in`, requiring a personal API key obtained via free self-service registration on data.gov.in ("Generate API Key" / "My Account"). We tested the commonly-circulated public sample key (`579b464d...`) against a specific resource ID and got `{"error": "Key not authorised"}` — confirming that the sample key does **not** work for this dataset and a real registered key is required.
- **Format:** JSON/XML via API (confirmed pattern from a GitHub reference implementation, `kayalshri/commodityprice`, which parses an XML data source from this same family of data.gov.in resources); CSV bulk download also typically offered on data.gov.in resource pages (not directly confirmed for this specific resource due to the JS rendering issue).
- **Licensing:** Open Government License, India — permissive, includes commercial use, confirmed via search result summary of the resource description (not independently re-verified against the license text itself in this session).
- **Schema join potential:** Highest of any source — this is literally the upstream of the existing CSV, so column names/semantics (State, District, Market, Commodity, Variety, Grade, Arrival_Date, Min/Max/Modal Price, Commodity_Code) should match closely or exactly, assuming the API is queried the same way the original CSV snapshot was generated.

### 3. AGMARKNET direct portal ("Agmarknet 2.0")

- **URL:** https://agmarknet.gov.in / https://www.agmarknet.gov.in — the legacy ASP.NET report pages (e.g., `SearchCmmMkt.aspx`, `PriceAndArrivals/DatewiseCommodityReport.aspx`) now redirect to or have been replaced by a new React/JS single-page app titled "Agmarknet 2.0" (confirmed via direct fetch: page title, meta description "Agmarknet 2.0", keywords "Agmarknet, agriculture market, mandi prices, agri commodities, farmers portal, India agriculture"). The old page returned only ~1KB of shell HTML with no server-rendered report content, form dropdowns, or year lists — **static fetching cannot verify functional details**; an interactive/JS-capable session would be needed.
- **Organization / authority:** Directorate of Marketing & Inspection, Ministry of Agriculture and Farmers Welfare, Government of India — the primary authoritative source underlying both data.gov.in and CEDA.
- **Years available:** AGMARKNET was launched in March 2000 (confirmed via ies.gov.in/Arthapedia). Public descriptions (Indian Economic Service / Arthapedia entry, fetched directly) describe daily max/min/modal price data, weekly/monthly trend reports, and commodity profiles, implying deep historical archives exist on this portal, but **the actual selectable year range, and whether Telangana's 13 districts / 188 markets are all represented historically, could not be confirmed in this research pass** due to the JS rendering barrier.
- **Coverage:** ~1,800 connected markets nationally per Arthapedia (as of that source's writing — could be dated), ~300 commodities / ~2,000 varieties tracked network-wide.
- **Mechanism:** Interactive web reports only (select state/district/market/commodity/date range, generate report) — this is a manual/scraping-style acquisition path, not a clean bulk API. Historically, third parties (e.g., the GitHub scraper "jha-vineet69/AgriMarket," found in search results but not independently vetted here) have built scrapers against this exact portal, which further confirms this is not designed as a bulk-API-first source.
- **Recommendation implication:** Useful as a **fallback verification / spot-check tool** (e.g., manually looking up "tomato Warangal 2024" to sanity-check numbers pulled from data.gov.in or CEDA), not as a primary automated ingestion pipeline, given the scraping burden and JS-app redesign.

### 4. Telangana Open Data Portal — "Daily Prices of Market Yard Commodities in Telangana"

- **URL:** https://data.telangana.gov.in/dataset/daily-prices-market-yard-commodities-telangana (dataset listing), portal root https://data.telangana.gov.in
- **Organization / authority:** Government of Telangana's official open data portal (built on the CivicActions "data-catalog-app" front end, confirmed by inspecting page source: `webpackJsonp@civicactions/data-catalog-app`).
- **What we could confirm:** The dataset exists, is explicitly titled/scoped to Telangana, and is listed under the portal's "agriculture" collection (https://data.telangana.gov.in/collection/agriculture, found via search).
- **What we could NOT confirm:** Years of coverage, update frequency, exact fields, download formats, and licensing. The dataset detail page is a client-rendered SPA; our static fetch returned only the app shell (`<div id="root"></div>` with no server-rendered content). We attempted the portal's `/data.json` DCAT-style catalog endpoint and a metastore-item endpoint (patterns common to CivicActions/DKAN-based portals) — both returned empty/no usable output in this session. **This source needs a follow-up pass with a JS-capable browser tool (or direct outreach to the Telangana Agriculture Marketing Dept) before it can be relied on.**
- **Provisional rank rationale:** Ranked B (not A) specifically *because* we could not verify it, despite it being the most on-the-nose named source (official Telangana government + explicitly agriculture market-yard prices). If a follow-up verification confirms multi-year daily data with market-level granularity, this should likely be promoted to A, since it would be the most authoritative Telangana-specific source available and might have data AGMARKNET's national feed lacks or reports later than the state does.
- Separately, the Telangana Department of Agricultural Marketing's operational site (`eagrimarket.telangana.gov.in`) was fetched directly and confirmed to be a **license/registration administration portal only** (trader/commission-agent/warehouseman licensing forms) — it does **not** host historical price data or reports, despite superficially sounding like the right department site. Do not confuse this with the actual price dataset host.

### 5. eNAM (National Agriculture Market)

- **URL:** https://enam.gov.in
- **Organization / authority:** Small Farmers' Agribusiness Consortium (SFAC), Government of India.
- **Years available / historical API:** Not confirmed. Search results describe eNAM as primarily a **live electronic trading platform** (bidding, arrivals, current price info via mobile app) rather than a historical data archive product. Network stats found (1,389 mandis in 2024 → 1,656 mandis as of March 2026, "23 States and 4 UTs," "90+ commodities") describe platform scale, not data archive depth.
- **Mechanism:** Portal + mobile app for traders/farmers; **no public bulk historical price API was found or confirmed** in this research pass. Obtaining eNAM historical data would likely require direct engagement with SFAC.
- **Rank rationale (C for this use case):** Not ruled out as *valuable* data, but currently un-verifiable as an *accessible bulk source* for backfilling 2022–2024 history without direct institutional contact — deprioritized relative to CEDA and data.gov.in, which have confirmed programmatic access paths.

### 6. Kaggle community-uploaded datasets (supplemental only)

- Examples found: "Indian Agricultural Mandi Prices (2023–2025)" (onion/tomato/potato/wheat/rice, per uploader's Kaggle listing), "Agmarknet India Commodity Prices (Oct'24–Aug'25)," "Current Daily Price of Various Commodities in India" (updated May 2025, per search result).
- **Not independently verified** — these are third-party re-uploads, typically themselves scraped or exported from AGMARKNET/data.gov.in, with dataset date ranges as self-reported by the uploader in the listing title (not confirmed by us against the actual file). Licensing varies per uploader and is often unclear for commercial reuse.
- **Rank: C, supplemental only.** Could be useful as a fast prototyping/sanity-check dataset, or to validate a CEDA/data.gov.in pipeline's output against an independent scrape, but should not be treated as a primary or authoritative production data source given unverifiable provenance and license ambiguity.

## Recommendation

**Primary path: pursue data.gov.in's AGMARKNET-sourced API first, with CEDA as parallel/backup and cross-validation.**

1. **data.gov.in (Rank A) — start here.** It is the same upstream lineage as the existing `historical_mandi_prices.csv`, so schema alignment (State/District/Market/Commodity/Variety/Grade/Arrival_Date/Min/Max/Modal Price) should require the least transformation work, and its license (Open Government License, India) is the most permissive of the sources checked, with no non-commercial restriction confirmed. **Concrete next step (not yet done in this research pass, needs an engineer with a registered API key):** register a real data.gov.in API key, then query the "Variety-wise Daily Market Prices Data of Commodity" resource with `filters[state]=Telangana` and `filters[arrival_date]` set to a 2022–2024 range, to directly determine (a) whether historical dates beyond the current window are actually returned (given the unconfirmed "15-day rolling history" concern noted above), and (b) whether data.gov.in's separate year-archived resources (like the "Tinda 2021" pattern found) exist for the commodities and years YieldAI needs. This single API test will resolve the biggest open uncertainty in this whole research task.

2. **CEDA Agri Market Data (Rank A) — use in parallel, primarily for cross-validation and possibly for the actual backfill if data.gov.in's historical window turns out to be limited.** CEDA's own citation string ("CEDA Agri Market Data (CEDA-AMD), 2000–2023") is the most concrete, self-declared multi-year range found for any source in this research, and it has a real documented API — but **its terms restrict free use to non-commercial purposes**, which is a real legal/licensing question the team must resolve (contact CEDA, or restrict CEDA data to internal validation/backtesting rather than shipping it in a commercial product) before relying on it for production. Also confirm whether CEDA's price data is daily/market-level or aggregated to monthly/district — if aggregated, it may not support the "tomato price in Warangal on a specific day" granularity YieldAI's model wants, even though it's good for validating rebuilt trend directions.

3. **Telangana Open Data Portal (currently Rank B, unverified) — assign someone to re-check with a JS-capable browser** (this research pass's static-fetch tools could not render its SPA). If it turns out to have genuine multi-year, market-level Telangana data directly from the state government, it should become the top-priority source, since it is both authoritative and Telangana-specific (potentially catching state-level detail or timeliness the national AGMARKNET feed misses).

4. **AGMARKNET direct portal — keep as a manual spot-check / scraping fallback only**, not a primary ingestion pipeline; it requires JS rendering and has no confirmed bulk API.

5. **eNAM and Kaggle datasets — deprioritize.** eNAM lacks a confirmed accessible historical bulk-data path; Kaggle datasets are unverified third-party re-exports unsuitable for a production pipeline, though usable for quick prototyping.

**Honesty note on what remains unverified:** The single most consequential open question — whether data.gov.in's API actually returns multi-year (2022–2024) Telangana records when queried with date filters, versus only a rolling recent window — could **not** be resolved in this research pass because it requires a registered API key (self-service signup, not completed here) to test live. This should be the first concrete engineering task before committing to a backfill architecture. Similarly, the Telangana state portal's actual dataset content was not renderable by the tools available in this session and needs a follow-up check.
